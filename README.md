# Estudos de Laravel

Roteiros progressivos para aprender rotas, controllers, Blade, migrations e CRUD. Cada pasta descreve um mini projeto para implementar e ampliar.

## Mini projetos

1. `mini-projetos/01-lista-de-tarefas/`: CRUD de tarefas com arquivos de partida para model, migration, controller, rotas e view Blade.
2. `mini-projetos/02-catalogo-de-livros/README.md`: migrations, relacionamento simples e filtros.
3. `exemplos/routes-web.php`: exemplos iniciais de rotas.

## Como executar

Instale PHP, Composer e os requisitos indicados pela documentação do Laravel. Crie uma aplicação com `composer create-project laravel/laravel app`, configure o banco no `.env`, siga o README de cada mini projeto, execute `php artisan migrate` e inicie com `php artisan serve`.

Este repositório contém roteiros e exemplos de estudo; os mini projetos são pontos de partida, não aplicações concluídas.
